# ShutterScope 0.1

首个 Windows x64 便携版本，采用 GPLv3（GPL-3.0-only）。

支持实时波形、噪声校准、快慢门与 B 门检测、游标测时、WAV 导入和 CSV/WAV 导出。默认检测模式按独立的开启与关闭光变沿计时，最长等待 30 秒。

## 下载

- `ShutterScope-0.1-windows-x64.zip`：解压后运行 `ShutterScope.exe`，无需安装 Python。
- `ShutterScope-0.1-source.zip`：对应源码、测试样本与构建脚本。
- `SHA256SUMS.txt`：两个压缩包的 SHA256 校验值。

Windows 程序未签名，使用标准 PortAudio 驱动，不含 ASIO。完整项目许可和第三方声明随便携包提供。

回放样本包含短快门、B 门和连续闪烁信号；自动构建运行回归测试、GUI 检查及冻结程序自检。结果是局部曝光估计，没有标准计时仪校准值，不能把显示小数位当作硬件准确度。
