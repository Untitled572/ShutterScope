# 使用说明

## 连接与输入

使用稳定常亮光源照射快门，将二极管放在快门后方要测量的位置。让光路经过快门，再到二极管，减少周围漏光。手电信标可以检查信号通路，但实际测快门时应使用常亮光源。

选择与二极管连接的实体输入。程序优先选择可用的 Realtek WASAPI 输入，否则使用系统默认输入；系统默认设备也可能是虚拟麦克风。没有波形时检查光路、设备和声道，不要只看设备名称。

默认请求 48000 Hz。设备不支持时会提示，可以改用受支持的采样率或同名设备的其他音频接口。更高的请求采样率不保证声卡模拟带宽更高，也不保证没有重采样。

遮光校准使用最近半秒估计基线和噪声。先遮住二极管，等信号稳定，再校准；光源闪烁或快门动作期间不适合校准。建议在系统或声卡软件中关闭降噪、自动增益和回声消除，软件不会更改这些设置。

## 四种检测模式

### 快慢门 · 光变沿配对（默认）

分别识别开启和关闭时的局部电平变化，各自在局部前后电平的 50% 位置计时。关闭沿无需跨过与开启对称的电压。麦克风交流耦合使信号在曝光中衰减回零时，程序仍等待真正的关闭光变。

三点中值用于抑制单点尖峰。程序检查局部净变化、边沿过渡时间和连续采样；关闭沿还需达到开启沿一定比例的幅度与斜率，以过滤过冲和缓慢回摆。默认最长等待 30 秒，等待时会显示已开启多久。

### 光电脉冲 · 半高宽

以遮光基线和脉冲峰值计算 50% 高度，在同一高度的两个交点之间计时。触发阈值只用于定位事件，不直接作为计时电平。图中会增加一条 50% 水平线。

适合边沿清楚、能形成完整单向脉冲的信号。交流耦合慢门会在真实关闭前衰减，因此不适合直接使用整段半高宽。该模式保留用于短脉冲核对。

### 开闭沿配对 · AC

配对相反极性的固定阈值交叉，使用单样本斜率过滤。适合形成两个独立正负边沿的信号。若关闭后的反向回摆低于阈值，会无法完成配对；可改用默认快慢门模式。

### 电平脉冲 · DC

按指定固定电平测脉宽，用释放门限和连续采样确认下降。结果会随阈值改变，可作为固定电平计时对照。

## 参数

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 触发阈值 | 5% 满量程 | 过低可能触发噪声，过高可能漏掉弱信号；遮光校准会调整它 |
| 预计档位 | 不限 | 选择后只接受其 ¼–4 倍时长，不会把测量值修正到预计值 |
| 开沿极性 | 负向 | 取决于接线与受光响应；也可选正向或自动 |
| 连续确认 | 3 个采样点 | 抑制毛刺；增大后可能漏掉很短的脉冲 |
| 最大边沿过渡 | 3 ms | 用于快慢门与半高宽模式；慢响应硬件可适当增大 |
| 闭沿最小幅度比 | 35% | 默认模式中相对开启沿的局部幅度，降低后更容易接纳较弱关闭沿及过冲 |
| 闭沿最小斜率比 | 8% | 默认模式中相对开启沿的斜率，用于过滤缓慢回摆 |
| 最短曝光 | 0.05 ms，且至少 3 个采样间隔 | 小于下限的事件被丢弃 |
| 最长曝光 | 30 s | 当前允许上限为 30 秒；未知速度应保持预计档位不限 |
| 测量后冷却 | 10 ms | 只对成功测量生效，拒绝毛刺后立即重新等待 |
| 边沿斜率 | 100%FS/ms | 仅 AC 模式使用；设 0 关闭，关闭后需在基线附近稳定再触发 |

## 查看与保存

测量完成后自动捕获波形，后台继续测量。使用滚轮或按钮缩放，冻结后点击两点读取手动时间差；手动游标不写入自动历史。“全览”恢复完整捕获区间。

历史保留整个会话，原始波形保留最近 10 条。退出前导出需要的 CSV 和 WAV；更早记录的数值仍可导出。模拟信号会明确标注来源，不改动实时输入参数。

支持小于 128 MB 的 8/16/24/32 位整数 PCM WAV。使用当前模式、极性、阈值和所选声道，按文件自身采样率分析；暂不支持浮点或压缩 WAV。CSV 使用带 BOM 的 UTF-8，WAV 导出为 16 位单声道整数 PCM。

## 没有结果时

先看状态栏的输入峰值和阈值。信号低于阈值时检查光路与输入声道；有清晰开闭沿但不输出时，检查极性、预计档位范围、最长曝光及所选模式。

B 门等待时，状态栏应显示已开启时长。超过最长曝光仍未找到关闭沿会丢弃本次事件。默认模式不把曝光中的回零作为关闭。

音频丢帧会暂停测量并丢弃未完成事件；无回调超过 2 秒会关闭输入。达到数字满量程的削顶事件不输出结果，模拟电路限幅还需目视检查。

## 时间与准确度

计时使用音频采样点，边沿位置采用线性插值，不使用界面刷新或回调到达时间。44.1 kHz、48 kHz 的采样间隔分别约 22.68 μs、20.83 μs；这些值不是硬件准确度保证。

单只二极管反映的是所在位置。声卡滤波、二极管响应、光源和快门几何形状均可能影响结果，仍需核对波形；测量不能代替完整画幅均匀性检查或标准计时仪校准。
